前綴和與差分

學習目標

  • 理解前綴和（Prefix Sum）如何把區間和查詢降到 O(1)。
  • 能寫出一維與二維前綴和。
  • 學會差分（Difference Array）處理大量區間加值。

核心觀念

定義 pre[i] = a[1] + … + a[i]，且 pre[0] = 0。那麼區間 [l, r] 的和就是「前 r 個的和」減掉「前 l−1 個的和」。

sum(l, r) = pre[r] − pre[l−1]。差分則是前綴和的反運算：在 d[l] += v、d[r+1] −= v，最後做一次前綴和即可。

範例演示

a = [3, 1, 4, 1, 5]（1-indexed），查詢 sum(2, 4)：

i012345
a[i]—31415
pre[i]0348914

sum(2, 4) = pre[4] − pre[1] = 9 − 3 = 6，驗算 1 + 4 + 1 = 6 ✓。

程式碼

一維前綴和 + 差分

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 1), pre(n + 1, 0);   // 和可能超過 int
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
    }

    // 差分：對 [l, r] 全部加 v，多次操作後一次還原
    vector<long long> d(n + 2, 0);
    auto add = [&](int l, int r, long long v) { d[l] += v; d[r + 1] -= v; };
    add(1, 3, 10);
    add(2, 5, -2);
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];                 // d[i] 變成第 i 格的總增量
        cout << a[i] + d[i] << " \n"[i == n];
    }
}

二維前綴和

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<long long>> p(n + 1, vector<long long>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            long long x; cin >> x;
            // 上 + 左 − 重複算到的左上角
            p[i][j] = x + p[i - 1][j] + p[i][j - 1] - p[i - 1][j - 1];
        }
    int x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    cout << p[x2][y2] - p[x1 - 1][y2] - p[x2][y1 - 1] + p[x1 - 1][y1 - 1] << '\n';
}

複雜度

項目複雜度
預處理O(n)／二維 O(nm)
單次區間和查詢O(1)
差分單次區間加值O(1)，還原 O(n)
空間O(n)

常見錯誤

  • 索引差一：用 1-indexed 並讓 pre[0] = 0，就不用特判 l = 1。
  • 溢位：n = 2×10⁵、值 10⁹ 時總和超過 int，前綴和一律用 long long。
  • 差分陣列開太小：會寫到 d[r+1]，要開 n + 2。

  • 「多次區間加值、最後才問」→ 差分。
  • 二維公式記「加上、加左、減左上」。
