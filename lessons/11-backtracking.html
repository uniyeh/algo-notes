回溯 Backtracking

學習目標

  • 理解回溯（Backtracking）就是「在決策樹上做 DFS」。
  • 能寫出「做選擇 → 遞迴 → 撤銷選擇」的模板。
  • 會用剪枝減少搜尋量。

核心觀念

排列、組合、子集、N 皇后這類「列出所有可能」的題目，可以畫成一棵決策樹：每一層做一個選擇。回溯就是 DFS 走這棵樹，走到底就記錄答案，回來時把選擇撤銷。

模板三步：path.push_back(選擇) → dfs(...) → path.pop_back()。

範例演示

列出 [1, 2, 3] 的全排列，前幾步：

path動作
[1]選 1
[1, 2]選 2
[1, 2, 3]長度 3 → 輸出
[1, 2]撤銷 3
[1]撤銷 2
[1, 3]改選 3 → 繼續

程式碼

全排列模板

#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> path;
vector<bool> used;

void dfs() {
    if ((int)path.size() == n) {                 // 走到葉子：記錄答案
        for (int x : path) cout << x << ' ';
        cout << '\n';
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;
        used[i] = true; path.push_back(i);       // 做選擇
        dfs();
        used[i] = false; path.pop_back();        // 撤銷選擇
    }
}

int main() {
    n = 3;
    used.assign(n + 1, false);
    dfs();
}

複雜度

項目複雜度
全排列O(n · n!)
組合 C(n, k)O(k · C(n, k))
子集O(n · 2ⁿ)
遞迴空間O(n)

常見錯誤

  • 忘記撤銷選擇：path 或 used 沒恢復，後面的分支全錯。
  • 組合題重複：組合要從 start 往後選，否則 [1,2] 和 [2,1] 會重複出現。
  • 沒剪枝：剩下的數字不夠湊滿 k 個時可以提早結束，例如 i <= n - (k - path.size()) + 1。

  • 回溯 = 在決策樹上 DFS。
  • 做選擇 → 遞迴 → 撤銷選擇。
  • 組合用 start 避免重複，剪枝砍掉不可能的分支。
