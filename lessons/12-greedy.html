貪婪 Greedy

學習目標

  • 理解貪婪法（Greedy）：每一步選當下最好的。
  • 能用「交換論證」說服自己貪婪是對的。
  • 熟悉區間排程、分配類的經典模型。

核心觀念

貪婪法每一步都做局部最佳選擇，並且不回頭。它很快，但不一定正確，所以要能說出理由：常用的是交換論證——如果最佳解不是這樣選，把它換成貪婪的選擇不會變差。

區間排程：按結束時間排序，能選就選。結束越早，留給後面的空間越多。

範例演示

區間 [1,3]、[2,5]、[3,4]、[5,7]，按結束時間排序後：

區間開始 ≥ 上次結束？選擇上次結束
[1,3]是選3
[3,4]3 ≥ 3 是選4
[2,5]2 ≥ 4 否跳過4
[5,7]5 ≥ 4 是選共 3 場

程式碼

分配餅乾與跳躍遊戲

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 分配餅乾：用最小的餅乾滿足胃口最小的孩子
    vector<int> g = {1, 2, 3}, s = {1, 1};
    sort(g.begin(), g.end());
    sort(s.begin(), s.end());
    int child = 0;
    for (int c : s)
        if (child < (int)g.size() && c >= g[child]) child++;
    cout << child << '\n';                     // 1

    // 跳躍遊戲：維護目前能到的最遠位置
    vector<int> a = {2, 3, 1, 1, 4};
    int far = 0;
    bool ok = true;
    for (int i = 0; i < (int)a.size(); i++) {
        if (i > far) { ok = false; break; }    // 走不到 i
        far = max(far, i + a[i]);
    }
    cout << (ok ? "YES" : "NO") << '\n';       // YES
}

複雜度

項目複雜度
排序O(n log n)
掃描O(n)
空間O(1)（不含輸入）

常見錯誤

  • 沒證明就貪：例如找零錢用「先拿最大面額」在 {1, 3, 4} 湊 6 會得到 4+1+1，但最佳是 3+3，這時要用 DP。
  • 區間按開始時間排序：一個很早開始但很晚結束的區間會擋住所有人。
  • 相等邊界：題目允許「結束 = 開始」時用 >=，不允許時用 >。
