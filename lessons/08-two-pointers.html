雙指針 Two Pointers

學習目標

  • 理解雙指針（Two Pointers）把 O(n²) 降到 O(n) 的原理。
  • 能寫出「左右夾逼」與「滑動視窗」兩種模板。
  • 知道滑動視窗需要的單調條件。

核心觀念

雙指針有兩種常見型態：

  • 左右夾逼：排序後一個從左、一個從右，依大小決定移哪邊（Two Sum、三數之和）。
  • 滑動視窗（Sliding Window）：兩個指針都往右走，維護一段「合法」的連續區間。

兩個指針都只往一個方向走，總共最多移動 2n 次，所以是 O(n)。

範例演示

排序陣列 [1, 2, 4, 7, 11] 找和為 9：

步驟lra[l]+a[r]動作
10412 > 9r−−
2038 < 9l++
3139找到 (2, 7)

程式碼

左右夾逼：排序後的 Two Sum

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {1, 2, 4, 7, 11};
    int target = 9;
    int l = 0, r = a.size() - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target) { cout << a[l] << ' ' << a[r] << '\n'; break; }
        if (s < target) l++;       // 太小：只有左邊變大才有機會
        else r--;                  // 太大：只有右邊變小才有機會
    }
}

滑動視窗：最長無重複字元子字串

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s = "abcabcbb";
    vector<int> cnt(256, 0);
    int best = 0;
    for (int l = 0, r = 0; r < (int)s.size(); r++) {
        cnt[(unsigned char)s[r]]++;
        while (cnt[(unsigned char)s[r]] > 1)      // 視窗不合法就縮左邊
            cnt[(unsigned char)s[l++]]--;
        best = max(best, r - l + 1);
    }
    cout << best << '\n';                          // 3（"abc"）
}

複雜度

項目複雜度
左右夾逼O(n)（不含排序）
滑動視窗O(n)
空間O(1) ~ O(字元集)

常見錯誤

  • 陣列有負數還用滑動視窗求和：加入元素不一定讓和變大，單調性消失，視窗就不成立（要改用前綴和）。
  • 夾逼前沒排序：左右夾逼依賴排序後的大小關係。
  • 視窗長度差一：閉區間 [l, r] 長度是 r - l + 1。

重點回顧

  • 左右夾逼：排序後依大小移動一邊。
  • 滑動視窗：右邊擴張、不合法就縮左邊。
  • 視窗求和需要元素皆為正（單調性）。
