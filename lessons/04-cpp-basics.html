前序：複雜度與 C++ 競程基礎

學習目標

  • 理解時間複雜度（Time Complexity）與「一秒 10⁸」的估算法。
  • 能寫出競程標準開頭與快速輸入輸出。
  • 會用 vector、sort、long long 等最常用工具。
  • 知道什麼時候會溢位、怎麼避免。

核心觀念

寫題目之前先問兩件事：資料有多大？、答案有多大？。前者決定演算法要多快，後者決定變數型別。

C++ 一秒大約能跑 10⁸ 次簡單運算。看到 n ≤ 2×10⁵，就知道 O(n²) 會跑 4×10¹⁰ 次，一定超時，要找 O(n log n) 以下的做法。

先看資料範圍反推複雜度，再選演算法——這是所有章節的共同起點。

範例演示

同一題「找陣列中是否有兩數相同」，n = 2×10⁵：

做法複雜度運算次數結果
兩層迴圈比對O(n²)4×10¹⁰TLE
先排序再比相鄰O(n log n)約 3.6×10⁶AC
雜湊表O(n)2×10⁵AC

程式碼

競程標準模板

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 關閉與 C 的同步、解除 cin/cout 綁定，大量輸入時快很多
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);          // 值到 1e9、加總會超過 int，用 long long
    for (auto &x : a) cin >> x;

    sort(a.begin(), a.end());        // O(n log n)
    bool dup = false;
    for (int i = 1; i < n; i++)
        if (a[i] == a[i - 1]) dup = true;

    long long sum = accumulate(a.begin(), a.end(), 0LL);  // 0LL：讓加總用 long long
    cout << (dup ? "YES" : "NO") << ' ' << sum << '\n'; // '\n' 比 endl 快（endl 會強制清空緩衝）
}

複雜度

項目複雜度
排序O(n log n)
掃描一次O(n)
空間O(n)

常見錯誤

  • int 溢位：int 上限約 2.1×10⁹，兩個 10⁹ 相加就爆。加總、乘法一律先想 long long。
  • accumulate 初值寫 0：會用 int 加總，要寫 0LL。
  • 大量輸出用 endl：每次都清空緩衝，可能因此 TLE。
