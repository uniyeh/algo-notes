廣度優先搜尋 BFS

學習目標

  • 理解廣度優先搜尋（Breadth-First Search）「一層一層擴散」的順序。
  • 能用佇列寫出鄰接串列版與網格版 BFS。
  • 知道為什麼 BFS 能求無權圖最短路。

核心觀念

從起點丟一顆石頭進水裡，漣漪一圈一圈往外擴。BFS 用佇列（Queue）實現：先進先出，保證距離為 d 的點全部處理完，才會處理距離 d+1 的點。

每個點第一次被拜訪時的距離就是最短距離——所以「入隊時」就要標記 visited。

範例演示

圖：1–2, 1–3, 2–4, 3–4, 4–5，從 1 出發：

程式碼

鄰接串列版

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    vector<int> dist(n + 1, -1);   // -1 同時代表「沒拜訪過」
    queue<int> q;
    dist[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;     // 入隊時就標記，避免重複入隊
            q.push(v);
        }
    }
    for (int i = 1; i <= n; i++) cout << dist[i] << " \n"[i == n];
}

網格版（迷宮最短路）

#include <bits/stdc++.h>
using namespace std;

const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};

int main() {
    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto &row : g) cin >> row;      // '.' 可走、'#' 牆
    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    dist[0][0] = 0;
    q.push({0, 0});
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || ny < 0 || nx >= n || ny >= m) continue;
            if (g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << dist[n - 1][m - 1] << '\n';   // -1 表示走不到
}

複雜度

項目複雜度
時間（鄰接串列）O(V + E)
時間（網格）O(nm)
空間O(V + E)

常見錯誤

  • 出隊才標記：同一個點會被多次加入佇列，最壞變成指數級或 TLE。一定要入隊時標記。
  • 拿 BFS 做有權圖：邊權不同時 BFS 不保證最短，要改用 Dijkstra（邊權只有 0/1 可用 0-1 BFS）。
  • 網格邊界：先檢查 nx, ny 是否越界，再讀 g[nx][ny]。

重點回顧

  • BFS = 佇列 + visited，一層一層擴散。
  • 無權圖最短路首選 BFS，複雜度 O(V + E)。
  • 入隊時標記，永遠不要出隊才標記。
