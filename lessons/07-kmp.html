字串匹配 KMP

學習目標

  • 理解暴力字串匹配為什麼會慢。
  • 理解前綴函數（Prefix Function，又稱 next / failure 陣列）的意義。
  • 能寫出 O(n + m) 的 KMP 搜尋。

核心觀念

在文字 t 中找模式 p，暴力法每次失配就把 p 右移一格重來，最壞 O(nm)。KMP 的想法：失配時，已經比對成功的那段資訊不要浪費。

前綴函數 f[i]：p[0..i] 中「既是前綴又是後綴」的最長長度（不含整段）。失配時把 j 跳到 f[j-1]，t 的指標永遠不後退。

KMP 的核心就是一句話：失配時，用 f[] 告訴你「模式最多可以保留多少」。

範例演示

p = "abaab" 的前綴函數：

i01234
p[i]abaab
f[i]00112

f[4] = 2：「abaab」的前綴 "ab" 與後綴 "ab" 相同。

程式碼

前綴函數 + 搜尋

#include <bits/stdc++.h>
using namespace std;

vector<int> prefixFunction(const string &p) {
    int m = p.size();
    vector<int> f(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = f[j - 1];   // 失配：退回次長的相同前後綴
        if (p[i] == p[j]) j++;
        f[i] = j;
    }
    return f;
}

int main() {
    string t = "aabaabaab", p = "abaab";
    vector<int> f = prefixFunction(p);
    for (int i = 0, j = 0; i < (int)t.size(); i++) {
        while (j > 0 && t[i] != p[j]) j = f[j - 1];
        if (t[i] == p[j]) j++;
        if (j == (int)p.size()) {
            cout << "found at " << i - j + 1 << '\n';
            j = f[j - 1];                              // 繼續找下一個（允許重疊）
        }
    }
}

複雜度

項目複雜度
建前綴函數O(m)
搜尋O(n)
空間O(m)

常見錯誤

  • while 寫成 if：失配時可能要連續退好幾次，必須用 while。
  • 找到後沒有更新 j：j 會超出模式長度，要設成 f[j-1]。
  • 大量輸入用 getline 混 cin：殘留換行字元造成讀錯，只讀單字時直接用 cin。

重點回顧

  • KMP：文字指標不後退，總共 O(n + m)。
  • f[i] = 最長相同前後綴長度。
  • 失配用 while 退，找到後 j = f[j-1]。
