堆疊與佇列 Stack & Queue

學習目標

  • 理解堆疊（Stack，後進先出）與佇列（Queue，先進先出）。
  • 能用堆疊解括號匹配、運算式求值。
  • 認識雙端佇列 deque 與滑動視窗最大值。

核心觀念

堆疊像一疊盤子，只能從最上面拿放：push、top、pop。佇列像排隊，從尾端進、前端出。兩端都能進出的是 deque。

只要問題有「最近的一個還沒處理完的東西」（例如最近一個左括號），就是堆疊的味道。

「配對最近的」→ 堆疊；「按到達順序處理」→ 佇列。

程式碼

堆疊：逆波蘭表示法求值

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<string> tokens = {"2", "1", "+", "3", "*"};   // (2 + 1) * 3
    stack<long long> st;
    for (auto &tk : tokens) {
        if (tk == "+" || tk == "-" || tk == "*" || tk == "/") {
            long long b = st.top(); st.pop();            // 注意先彈出的是右運算元
            long long a = st.top(); st.pop();
            if (tk == "+") st.push(a + b);
            else if (tk == "-") st.push(a - b);
            else if (tk == "*") st.push(a * b);
            else st.push(a / b);
        } else st.push(stoll(tk));
    }
    cout << st.top() << '\n';                            // 9
}

deque：滑動視窗最大值

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {1, 3, -1, -3, 5, 3, 6, 7};
    int k = 3;
    deque<int> dq;                    // 存索引，對應的值由大到小
    for (int i = 0; i < (int)a.size(); i++) {
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();  // 比我小的永遠不會是答案
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();                    // 過期的移出視窗
        if (i >= k - 1) cout << a[dq.front()] << ' ';
    }
    cout << '\n';                     // 3 3 5 5 6 7
}

複雜度

項目複雜度
push / pop / topO(1)
括號匹配O(n)
滑動視窗最大值O(n)
空間O(n)

常見錯誤

  • 對空堆疊呼叫 top()：未定義行為，常直接 RE；先檢查 empty()。
  • 彈出順序搞反：a - b 時先彈出的是 b。
  • 結束時沒檢查堆疊是否為空：(( 每一步都沒錯，但最後還有剩，仍然不合法。
