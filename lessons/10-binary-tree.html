二元樹 Binary Tree

學習目標

  • 理解二元樹（Binary Tree）的結構與術語。
  • 能寫出前序、中序、後序的遞迴走訪。
  • 能用 BFS 做層序走訪並求樹高。

核心觀念

二元樹每個節點最多兩個子節點。三種深度優先走訪只差在「處理自己」的時機：

  • 前序：自己 → 左 → 右
  • 中序：左 → 自己 → 右
  • 後序：左 → 右 → 自己

樹的題目幾乎都是遞迴：想清楚「左右子樹回傳什麼」，再決定自己怎麼合併。

範例演示

樹：1 的子節點是 2、3；2 的子節點是 4、5。

走訪結果
前序1 2 4 5 3
中序4 2 5 1 3
後序4 5 2 3 1
層序1 | 2 3 | 4 5
高度3

程式碼

遞迴走訪與層序走訪

#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left = nullptr, *right = nullptr;
    TreeNode(int v) : val(v) {}
};

void preorder(TreeNode *u) {
    if (!u) return;                 // 遞迴終止條件：空節點
    cout << u->val << ' ';
    preorder(u->left);
    preorder(u->right);
}

int height(TreeNode *u) {           // 後序思維：先知道左右子樹高度，再算自己
    if (!u) return 0;
    return max(height(u->left), height(u->right)) + 1;
}

int main() {
    TreeNode *root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);

    preorder(root);
    cout << "\nheight = " << height(root) << '\n';

    queue<TreeNode*> q;              // 層序走訪 = 樹上的 BFS
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();           // 這一層有幾個節點
        while (sz--) {
            TreeNode *u = q.front(); q.pop();
            cout << u->val << ' ';
            if (u->left) q.push(u->left);
            if (u->right) q.push(u->right);
        }
        cout << '\n';
    }
}

複雜度

項目複雜度
任一種走訪O(n)
遞迴空間O(h)，h 為樹高
層序走訪空間O(寬度)

常見錯誤

  • 忘記空節點的終止條件：直接存取 nullptr->left 會 RE。
  • 樹退化成鏈：n = 10⁵ 的鏈狀樹遞迴深度 10⁵，可能堆疊溢位；必要時改用迭代。
  • 層序走訪沒先記下層的大小：迴圈中佇列會變長，要先存 q.size()。
