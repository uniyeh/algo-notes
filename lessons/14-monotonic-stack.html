單調堆疊 Monotonic Stack

學習目標

  • 理解單調堆疊（Monotonic Stack）解決「下一個更大／更小」的原理。
  • 能寫出 O(n) 的單調堆疊模板。
  • 知道堆疊裡存索引而不是值的好處。

核心觀念

要找每個元素右邊第一個比它大的數，暴力是 O(n²)。單調堆疊的想法：堆疊裡放「還沒找到答案」的元素，並保持由底到頂遞減。新元素進來時，比它小的都找到答案了，就把它們彈出。

每個元素最多進出堆疊各一次，所以總共 O(n)。

範例演示

a = [2, 1, 2, 4, 3]，堆疊存索引（括號內為值）：

ia[i]彈出（找到答案）堆疊
02—0(2)
11—0(2) 1(1)
221 → 答案 20(2) 2(2)
342、0 → 答案 43(4)
43—3(4) 4(3)

答案：4 2 4 -1 -1（堆疊剩下的都是 -1）。

程式碼

每日溫度：還要等幾天才會更暖

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> t = {73, 74, 75, 71, 69, 72, 76, 73};
    int n = t.size();
    vector<int> ans(n, 0);
    stack<int> st;                      // 存索引：同時能拿到值和距離
    for (int i = 0; i < n; i++) {
        while (!st.empty() && t[st.top()] < t[i]) {
            ans[st.top()] = i - st.top();   // st.top() 等到了更暖的一天
            st.pop();
        }
        st.push(i);
    }
    for (int x : ans) cout << x << ' ';
    cout << '\n';                       // 1 1 4 2 1 1 0 0
}

常見錯誤

  • 單調方向搞反：找「下一個更大」要維持遞減堆疊；找「下一個更小」維持遞增。
  • < 和 <=：相等時要不要彈出，決定答案是「嚴格更大」還是「大於等於」。
  • 存值不存索引：求距離或位置時會拿不到資訊，習慣存索引。
