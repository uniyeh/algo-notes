二分搜尋

學習目標

  • 理解二分搜尋（Binary Search）成立的前提：單調性。
  • 能寫出不會無窮迴圈的左閉右開模板。
  • 學會「對答案二分」，把最佳化問題轉成判定問題。

核心觀念

想像一排答案，左邊全是「不行」、右邊全是「可以」。我們要找第一個「可以」。每次看中間：如果中間可以，答案在左半（含中間）；不行，答案在右半。每次砍掉一半，n 個候選只要約 log₂ n 次就找到。

二分搜的本質不是「在排序陣列找數字」，而是在一個 F F F … T T T 的判定函式上找分界點。

範例演示

在 a = [1, 3, 5, 7, 9, 11] 中找第一個 ≥ 7 的位置。區間 [lo, hi)：

步驟lohimida[mid] ≥ 7？動作
10637 → 是hi = 3
20313 → 否lo = 2
32325 → 否lo = 3
結束33——答案 = 3

程式碼

模板：找第一個滿足 check 的位置

#include <bits/stdc++.h>
using namespace std;

int n, k;
vector<int> a;

// 判定函式：必須是 F F F T T T 的形狀
bool check(int i) { return a[i] >= k; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> k;
    a.resize(n);
    for (auto &x : a) cin >> x;

    int lo = 0, hi = n;               // 左閉右開 [lo, hi)，hi = n 代表「找不到」
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2; // 避免 lo + hi 溢位
        if (check(mid)) hi = mid;
        else lo = mid + 1;
    }
    cout << lo << '\n';              // 等價於 lower_bound(a.begin(), a.end(), k) - a.begin()
}

對答案二分：最小化最大值

經典題：把 n 本書依序分給 m 人，求「最大負擔」的最小值。負擔上限 x 越大越容易成功 → 單調，可以二分 x。

#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<long long> w;

// 上限為 x 時，能否用不超過 m 人分完
bool ok(long long x) {
    int cnt = 1;
    long long cur = 0;
    for (long long v : w) {
        if (v > x) return false;
        if (cur + v > x) { cnt++; cur = 0; }
        cur += v;
    }
    return cnt <= m;
}

int main() {
    cin >> n >> m;
    w.resize(n);
    for (auto &v : w) cin >> v;
    long long lo = 0, hi = 1e15;      // 總和可能超過 int，用 long long
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (ok(mid)) hi = mid;
        else lo = mid + 1;
    }
    cout << lo << '\n';
}

複雜度

項目複雜度
陣列上二分（時間）O(log n)
對答案二分（時間）O(n log V)，V 為答案範圍
空間O(1)（不含輸入）

常見錯誤

  • 無窮迴圈：寫成 lo = mid 搭配 mid = (lo+hi)/2，當 hi = lo + 1 時 mid 永遠等於 lo。統一用左閉右開模板就不會遇到。
  • 判定函式不單調：先確認 check 真的是 F…T 的形狀，否則二分出來的答案沒有意義。
  • 溢位：(lo + hi) / 2 在接近 INT_MAX 時會溢位，改用 lo + (hi - lo) / 2。

重點回顧

  • 能二分的關鍵是單調性，不一定要是排序陣列。
  • 固定用左閉右開 [lo, hi) 模板，結束時 lo 就是答案。
  • 「求最小的最大值／最大的最小值」→ 先想對答案二分。
