雜湊表 Hash Table

學習目標

  • 理解雜湊表（Hash Table）為什麼能平均 O(1) 查找。
  • 能用 unordered_map / unordered_set 解題。
  • 學會「邊走邊查」的配對技巧（Two Sum）。

核心觀念

雜湊表把 key 透過雜湊函數換成陣列位置，查找、插入平均 O(1)。C++ 有兩組工具：unordered_map（無序、平均 O(1)）和 map（有序、O(log n)）。

經典用法是 Two Sum：走到 a[i] 時，問「之前有沒有出現過 k - a[i]」，有就配對成功。

「需要快速回答『某個值出現過嗎／出現幾次』」→ 第一個想到雜湊表。

範例演示

a = [2, 7, 11, 15]，找和為 9 的兩個索引：

ia[i]要找 9 − a[i]表中有嗎？表的內容
027沒有{2:0}
172有，索引 0答案 (0, 1)

程式碼

Two Sum 與次數統計

#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {2, 7, 11, 15};
    int k = 9;

    unordered_map<int, int> seen;          // 值 -> 索引
    for (int i = 0; i < (int)a.size(); i++) {
        auto it = seen.find(k - a[i]);     // 先查再放，避免自己配自己
        if (it != seen.end()) {
            cout << it->second << ' ' << i << '\n';
            break;
        }
        seen[a[i]] = i;
    }

    // 統計每個字母出現次數（判斷兩字串是否為重組字）
    string s = "anagram", t = "nagaram";
    unordered_map<char, int> cnt;
    for (char c : s) cnt[c]++;
    for (char c : t) cnt[c]--;
    bool ok = all_of(cnt.begin(), cnt.end(), [](auto &p) { return p.second == 0; });
    cout << (ok ? "YES" : "NO") << '\n';
}

複雜度

項目複雜度
查找／插入（平均）O(1)
查找／插入（最壞）O(n)
map 版本O(log n)
空間O(n)

常見錯誤

  • 用 m[x] 查詢：key 不存在時會自動插入 0，改變表的大小；只查詢請用 find 或 count。
  • 先放再查：會讓 a[i] 和自己配對，要先查再放。
  • 被卡雜湊：Codeforces 有人專門構造碰撞資料，必要時改用 map 或自訂雜湊。

重點回顧

  • 雜湊表：平均 O(1) 判斷「出現過嗎、幾次」。
  • Two Sum：走到 a[i] 先查 k − a[i]，再放入自己。
  • 查詢用 find，不要用 []。
