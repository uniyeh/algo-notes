鏈結串列 Linked List

學習目標

  • 理解鏈結串列（Linked List）與陣列的差異。
  • 能用指標寫出插入、刪除、反轉。
  • 學會競程常用的「陣列模擬鏈結串列」。

核心觀念

陣列在記憶體中連續排列，中間插入要把後面全部往後搬，O(n)。鏈結串列每個節點記住「下一個是誰」，插入、刪除只要改幾個指標，O(1)；代價是不能用索引直接跳到第 k 個。

需要「頻繁在中間插入／刪除」而且「手上已經有那個節點」時，鏈結串列才有優勢。

範例演示

串列 1 → 2 → 3，在 2 後面插入 7，再刪除 1：

步驟操作串列
0初始1 → 2 → 3
1nxt[7]=nxt[2], nxt[2]=71 → 2 → 7 → 3
2nxt[head]=nxt[1]2 → 7 → 3

程式碼

指標版：反轉鏈結串列（LeetCode 常見）

#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode *nxt = cur->next;   // 先存下一個，否則改完指標就找不到了
        cur->next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}

int main() {
    ListNode *head = nullptr, *tail = nullptr;
    for (int v : {1, 2, 3, 4}) {
        ListNode *node = new ListNode(v);
        if (!head) head = tail = node;
        else tail = tail->next = node;
    }
    for (ListNode *p = reverseList(head); p; p = p->next) cout << p->val << ' ';
    cout << '\n';
}

陣列模擬版：雙向鏈結串列（競程常用）

#include <bits/stdc++.h>
using namespace std;

const int N = 200005;
int L[N], R[N];          // L[x]、R[x]：x 左右的節點，0 當作頭尾哨兵

void insertAfter(int x, int y) {  // 在 x 右邊插入 y
    R[y] = R[x]; L[y] = x;
    L[R[x]] = y; R[x] = y;
}
void erase(int x) {
    R[L[x]] = R[x];
    L[R[x]] = L[x];
}

int main() {
    R[0] = L[0] = 0;               // 空串列：哨兵自己接自己
    insertAfter(0, 1);
    insertAfter(1, 2);
    insertAfter(2, 3);
    erase(2);
    for (int x = R[0]; x != 0; x = R[x]) cout << x << ' ';   // 1 3
    cout << '\n';
}

複雜度

項目複雜度
插入／刪除（已知節點）O(1)
找第 k 個O(n)
空間O(n)

常見錯誤

  • 改指標順序錯：先把 cur->next 改掉，就再也找不到下一個節點；先用暫存變數存起來。
  • 忘記處理頭節點：刪除頭節點要特判，或用哨兵（dummy head）統一處理。
  • 存取空指標：迴圈條件寫 while (cur)，不要直接 cur->next->next。

  • 鏈結串列：插入刪除 O(1)，隨機存取 O(n)。
  • 改指標前先暫存，善用哨兵節點。
  • 競程用 L[] / R[] 陣列模擬最快最穩。
