動態規劃 DP 與背包

學習目標

  • 理解動態規劃（Dynamic Programming）：把大問題拆成重疊的子問題。
  • 能定義狀態、寫出轉移式、決定初始值與順序。
  • 能寫出 0/1 背包的二維與一維寫法。

核心觀念

DP 五步驟：定義狀態 → 轉移式 → 初始值 → 計算順序 → 答案在哪。

爬樓梯：dp[i] = 走到第 i 階的方法數，dp[i] = dp[i-1] + dp[i-2]。
0/1 背包：dp[i][c] = 前 i 個物品、容量 c 的最大價值，每個物品「拿或不拿」：dp[i][c] = max(dp[i-1][c], dp[i-1][c-w] + v)。

一維背包要倒著枚舉容量，才能保證每個物品只用一次。

範例演示

容量 5，物品 (重量, 價值)：(1,1)、(2,6)、(3,10)。一維 dp[c] 每加入一個物品後：

加入c=012345
(1,1)011111
(2,6)016777
(3,10)016101116

程式碼

爬樓梯與 0/1 背包（二維）

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 爬樓梯：一次走 1 或 2 階
    int n = 10;
    vector<long long> dp(n + 1);
    dp[0] = 1; dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    cout << dp[n] << '\n';                    // 89

    // 0/1 背包（二維，最直觀）
    vector<int> w = {1, 2, 3}, v = {1, 6, 10};
    int W = 5, m = w.size();
    vector<vector<long long>> f(m + 1, vector<long long>(W + 1, 0));
    for (int i = 1; i <= m; i++)
        for (int c = 0; c <= W; c++) {
            f[i][c] = f[i - 1][c];                                    // 不拿
            if (c >= w[i - 1])
                f[i][c] = max(f[i][c], f[i - 1][c - w[i - 1]] + v[i - 1]); // 拿
        }
    cout << f[m][W] << '\n';                  // 16
}

複雜度

項目複雜度
爬樓梯O(n)
0/1 背包時間O(nW)
背包空間（二維 → 一維）O(nW) → O(W)

常見錯誤

  • 一維背包正著枚舉容量：同一個物品會被拿很多次，變成「完全背包」。
  • 初始值錯：求最大價值時 dp 初始為 0；若要求「剛好裝滿」，除了 dp[0] 外要設成負無限大。
  • 沒先定義狀態就寫轉移：一定先用一句中文說清楚 dp[i] 代表什麼。
